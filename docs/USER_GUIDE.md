# Social Info 普通用户操作指南

本指南适用于 Windows 10/11 x64。推荐通过 Edge 或 Chrome 扩展使用真实浏览器；不需要安装 Python、Conda 或编程工具。

## 1. 下载和安装

1. 打开 [GitHub Releases](https://github.com/949025590/Social-info/releases/latest)。
2. 下载 `SocialInfo-Setup.exe`。
3. 双击安装包，按提示完成安装。默认只安装到当前 Windows 用户，不需要管理员权限。
4. 建议保留桌面快捷方式；需要时可选“开机自动启动”。

## 2. 启动程序

双击桌面 **Social Info** 图标。

- 控制面板显示“服务已启动”即可使用。
- 关闭窗口只会隐藏到系统托盘，不会停止服务。
- 右键托盘图标可以重新打开控制面板、查看日志或退出。
- 只有完全退出才停止后台服务。

## 3. 安装 Edge/Chrome 扩展（首次一次）

Edge 操作如下；Chrome 的对应页面是 `chrome://extensions/`。

1. 在 Edge 地址栏输入 `edge://extensions/` 并回车。
2. 开启“开发人员模式”。
3. 点击“加载解压缩的扩展程序”。
4. 选择以下目录：

   ```text
   %LOCALAPPDATA%\Programs\SocialInfo\extension
   ```

   如果在资源管理器地址栏粘贴后无法直接选择，请先进入该目录，再返回上一级选中 `extension` 文件夹。

5. 安装后，在 Edge 扩展列表中确认 **Social Info 本地浏览器连接** 已启用。

## 4. 连接扩展

1. 按 `Win + R`，输入以下内容并回车：

   ```text
   %LOCALAPPDATA%\SocialInfo\extension-token.txt
   ```

2. 记事本会显示一串随机令牌，按 `Ctrl + A` 全选、`Ctrl + C` 复制。
3. 点击 Edge 右上角的拼图图标，再点击 **Social Info 本地浏览器连接**。
4. 将令牌粘贴到输入框，点击“连接本机服务”。
5. 看到“已连接本机服务”即完成。

令牌只用于本机连接，不需要发送给他人。不要把令牌提交到 GitHub。

## 5. 登录小红书

1. 在 Edge 中打开 [小红书](https://www.xiaohongshu.com)。
2. 使用正常页面扫码登录，不要开启 Edge 阅读器模式。
3. 如果某些笔记要求使用 App 扫码，请按页面提示操作；程序不会绕过限制。

程序也提供独立浏览器登录按钮，但真实 Edge/Chrome 扩展是推荐方式。

## 6. 连接本地 Agent

在支持 MCP 的 Agent 中添加：

```json
{
  "mcpServers": {
    "social-info": {
      "url": "http://127.0.0.1:8765/mcp"
    }
  }
}
```

该地址只监听本机 `127.0.0.1`，不是互联网服务。

连接后可直接对 Agent 说：

- “搜索小猫，读取前三篇可访问笔记的正文和互动数据。”
- “查看当前笔记的评论。”
- “切换到下一张图片。”
- “播放视频，定位到第 10 秒，再暂停并截图。”
- “返回搜索结果，选择下一篇。”

Agent 只能读取和浏览，不应点赞、关注、发布、评论、私信、删除或购买。

## 7. 常见问题

### 扩展显示未连接

- 确认 Social Info 托盘程序正在运行。
- 检查令牌是否完整复制。
- 在 `edge://extensions/` 中重新加载扩展，再打开弹窗检查状态。

### 提示没有小红书标签页

在 Edge 中打开小红书页面。新版扩展也支持由 Agent 自动新建标签页。

### 页面地址变成 `read://`

这是 Edge 阅读器模式。点击地址栏右侧的阅读器/书本图标退出，再回到普通小红书页面。

### 截图时出现短暂调试提示

截图通过浏览器调试接口完成，调用结束后会立即断开。扩展只选择小红书标签页执行该操作。

### 内容要求 App 扫码

这是平台对该账号或内容的访问要求。完成扫码或换其他可访问内容，不要连续刷新。

### 需要查看日志

在托盘控制面板点击“打开日志”，或打开：

```text
%LOCALAPPDATA%\SocialInfo
```

## 8. 卸载

在 Windows“已安装的应用”中卸载 Social Info。程序文件会删除；如需同时清除登录和令牌，可在卸载后手动删除：

```text
%LOCALAPPDATA%\SocialInfo
```

该目录包含登录状态，删除后下次需要重新登录和连接扩展。
